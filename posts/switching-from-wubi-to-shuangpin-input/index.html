从五笔转向双拼：一次输入法选择的回顾

我用了十几年五笔，最后换成了微软双拼。不是五笔不好，而是在原创写作这个场景里，形码从资产变成了负担。这篇文章不打算劝谁放弃五笔，只把从形码到声码的决策过程、一些史料、实验证据和几套双拼方案的实际差异摊开，给同样在纠结的人做个参照。

五笔的历史脉络：从南阳到新世纪

五笔字型通常追溯到王永民在南阳的研发。根据王码公开资料，第一代研发在1978到1983年，1986年定稿推广，称为86版。86版内部有体系差异，常见提到86-4.5版作为早期原始编码，后续有规范化版本。2000年前后推出的标准五笔字型/WB-18030，可以视为86体系在国标上的规范化延伸。

版本迭代大致是：

  • 86版：先发优势最重，至今仍是许多老用户、打字员和企事业单位的主流。
  • 98版：1993到1998年研发，增加整字字根，规范字根设计与取码，部分字根位置有调整。
  • 新世纪版：2008年1月28日推出，重做字根键位体系，可处理27533个简繁汉字，走彻底规范、亲近用户的路线。
  • WB-18030：86体系在国标大字符集上的规范化延伸，适合需要86但又要覆盖生僻字的用户。

常看到五笔用户有2000万到3000万的说法，公开资料很少给出可审计的全量数据。更稳妥的说法是行业估计：五笔曾是企业录入、政务、出版、速录培训的重要方案，86版因先发和教材生态占主导，98和新世纪长期小众。

仓颉：繁体思路下的形码

仓颉由朱邦复在1976年前后创制，最初叫形意检字法，后改名仓颉输入法。它用二十多个字母加辅助字形，重码低，逻辑偏繁体字形结构。1982年朱邦复公开放弃专利权，这件事在中文信息化史里很特别。对简体写作者来说，仓颉和五笔问题类似：脑子里是音，手上要转形。区别只在五笔更贴简体常用字根，仓颉更贴繁体部件逻辑。

关键转折：形码快，但快在哪

贴吧里有句话：形码适合抄稿，不适合边想边写。一开始觉得刺耳，后来看了一些研究，发现这话不算玄学。

几组可查的证据：

  1. 一项针对7到14岁学生的研究发现，形码整体输入速度快于音码，但选字框的信息量是影响速度的主要因素。换句话说，形码省选字，少中断视觉焦点；一旦候选框信息杂乱，优势会被吃掉。
  2. 周瀚和徐建平做过一个汉字输入认知实验，比较五笔和拼音，发现音码在看打和听打反应时差异不大，形码看打反应时少于听打。放到写作里就是：照稿看打，形码占优；听写口授，音码更直接；边构思边写，形码多一道音到形的翻译。
  3. 有认知研究总结，形码加工更自下而上，受字频和部件数影响小；音码更自上而下，受词频和语音通达影响大。
  4. 拼音为何后来反超：上世纪80年代字输入阶段，拼音同音字多，形码占优；90年代后词库、智能组词、上下文纠错成熟，拼音从全拼找字变成词语预测。汉语不标调音节约400个，标调1300多个，但常用词语语境下同音歧义可以被词库和模型消掉。

更准确结论不是五笔快还是拼音快，而是按场景分工：照稿录入、票据术语、固定文本，形码占优；聊天、开会记录、原创长文，音码更贴思维；双拼是全拼的折中，保留音码心想即音的低翻译成本，又把击键数压下来。

全拼太累，双拼才合理

全拼的问题不用多说：装zhuang六键，窗chuang六键，长句构思时手指滞后于语流。双拼规则简单，声母一键，韵母一键，一个音节两键，零声母各方案处理不同。真正难的是选哪套键位。

主流双拼方案按资料可这样定位：

方案来源键位特点跨平台适合谁
自然码周志农，1989韵母分配贴近拼音习惯，兼容性好各大PC/移动输入法多内置新手、经典派
微软双拼微软，1995基于自然码，ing放分号，部分韵母靠右Windows原生，mac/iOS/Android多内置多设备、企业环境
小鹤双拼何海峰，2009左右负荷均衡，可配音形辅助码百度/搜狗/PC前端支持好追求上限、愿练音形
搜狗双拼搜狗，2006零声母、纠错、词库深度绑定搜狗全平台好，换非搜狗要重配搜狗重度用户
拼音加加廖恒毅，1999规律性强，按拼音表感排，部分组合同手PC老前端有，移动参差老用户、桌面为主

个人的选择历程是：先拼音加加，规律好上手，但部分组合不均衡，手机端支持不好；尝试小鹤，键位均衡是真均衡，但音形要再练一套形码记忆，和逃离形码的初衷有点拧；回归自然码，资料丰富，但某些高频韵母重复按压，长时间写稿手指累；最后选择微软双拼，Windows原生，ing在分号，初学别扭但跨平台支持最佳。

把创作效率拆成可操作标准

与其说双拼适合写作，不如列四个指标：

  1. 思维翻译步数：全拼1步，五笔2步，双拼1步。边想边写优先1步。
  2. 击键数：全拼按音节长度，双拼固定2键，五笔通常1到4码。长句流水写，双拼更跟手。
  3. 选词中断：音码重码多但预测强，形码重码少但生造词可能不在码表。原创写作常造新词，音码反而松。
  4. 设备迁移：公司Win、家里Mac、手机iOS/Android，若每台上都要重装第三方加重登词库，长期成本高。微软双拼原生支持最省心。

按这套标准，纯照稿录入我仍会选五笔；多场景原创我选双拼。双拼里重原生选微软，重上限选小鹤，重老教程选自然码，重搜狗生态选搜狗。

RIME：五笔怀旧党的毛坯房

如果既舍不得五笔，又嫌知名互联网厂商输入法广告多，RIME（中州韵）是跨平台开源输入法方案。官方引擎支持Windows（小狼毫）、macOS（鼠须管）、Linux，移动端有同文、仓输入法等。配置是YAML配置文件：default.yaml处理全局与方案列表，weasel.yaml负责Windows前端，各schema.yaml管具体方案。用户改东西用default.custom.yaml等打补丁，重新部署生效。词库可扩展，可转化搜狗scel词库并导入RIME，可挂接OpenCC做简繁。五笔86可用现成码表方案，如wubi86-jidian。

收尾

从五笔到双拼，不是先进换落后，而是按场景重新分工。五笔的价值在照稿录入、在单字、在低频字和术语库；双拼的价值在边想边写、在跨设备、在不再维护一套形码记忆。牺牲一点单字盲打精度，换回来的是心里念一句手上出一句，不用先想这字怎么拆。
