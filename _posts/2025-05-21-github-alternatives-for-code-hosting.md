老实说，到了 2025、2026 年，GitHub 已经不再是“偶尔抽风”，而是经常出问题：免费 Actions 分钟数被大量机器人挖矿账号占用，正常用户排队很久；安全漏洞修复缓慢，供应链攻击时有发生；国内访问不稳定，CI/CD 一跑就卡，部署像抽奖。最让人不满的是，微软似乎不太在意免费用户，企业版卖得火热，免费用户却被忽视。

很多人忍无可忍，开始找备选。国内、海外、自建方案都看一看。

## 国内平台

国内平台普遍要求强制实名和手机号绑定，这是绕不开的门槛。

Gitee（码云）是目前国内最实用的选择。访问速度快、稳定性高，功能基本齐全：Pages、Wiki、Issues、PR、Release、Actions（虽弱但能用）。可以外链项目卡片，免费私有仓库多，中文社区完善。但 Actions 算力有限，免费额度用尽便无法使用，敏感内容可能被要求整改。如果人在国内、需要日常开发和速度，Gitee 是唯一靠谱的国产主力。

GitLink 由 CCF 和中科院背书，完全开源，支持 Pages、Wiki、Issue 等。但名字易与 GitLab 混淆，社区活跃度低，Issue 响应慢，国内访问一般。学术圈可考虑，日常开发还是 Gitee 更稳。

Coding（腾讯云）有大厂背书，企业级服务稳定，支持 CI/CD、项目管理、代码托管一体。但免费额度少，付费门槛高，界面臃肿，操作繁琐，数据隐私存疑。企业用户可考虑，个人开发者不建议。

## 海外平台

Codeberg 由德国非营利组织运营，完全开源，数据受 GDPR 保护。Pages 功能强，支持 Hugo/Jekyll 等静态生成器。社区友好，人工客服响应快。国内访问需代理，社区规模小。追求开源精神和隐私，这是首选。

GitLab 功能齐全，CI/CD、项目管理、托管一体，自托管版免费。但商业化重，免费版受限，国内访问慢。企业用户可考虑。

SourceHut 极简设计，无广告无追踪，完全开源。界面简陋，新手不友好，国内需代理。极简主义者可选，不适合大众。

## 自建方案

Gitea 轻量，资源占用低，完全开源，支持 Pages、Wiki、Issue 等。需自维护服务器和备份。有服务器资源的开发者首选。

OneDev 实现 DevOps 一体，托管加 CI/CD 加项目管理，轻量开源。同样需自维护。

GitHub 不再是唯一。国内用户可选 Gitee 主力，海外选 Codeberg 追开源，有服务器可自建 Gitea 或 OneDev。重要的是找适合自己的，而非被单一平台绑定。
