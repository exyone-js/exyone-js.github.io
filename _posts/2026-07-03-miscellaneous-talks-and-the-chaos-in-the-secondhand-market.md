## 关于 Zest

先提一句我做的 **Zest SSG**。今已至 `v0.3.1`，算是第一个稳定版本。性能增了许多（除却 FSI 冷启那免不了的二三秒），Zest Page 与 ZCSS 语法也大体可用了。但这月我得停更——要上学去。当前 GitHub 组织里只有我一人，没有其他管理员帮忙管理项目。

## 闲鱼二三事

闲鱼是个神奇的地方。这里几乎啥都有，黑市敢卖的它敢卖，黑市不敢卖的它也敢卖。抛开那些乌烟瘴气的，单从程序员视角看，在闲鱼搜 “GitHub”，出来的商品就让人瞳孔地震。最夸张的莫过于刷星、自动发货的账号交易、PR 造假、源码代下载……但这还不是最离谱的。最离谱的是各路商家晒着疑似脚本刷出来的贡献墙，明码标价兜售“大学生作业代做”。什么编程语言都接，装得跟真·技术大牛似的，买的人居然还不少。

我知道不少大学生进了大学就撒野放纵，但说句实话，玩归玩，闹归闹，**课别天天翘**，哪怕进去听一丁点儿呢？这纯属交冤枉钱。而且这些商家大概率也是拿 AI 做的项目，你花同样的钱买 Token 呢？至少能学会怎么用 AI，怎么 Vibe Coding，总比彻底躺平、不学无术强吧？抖音、B站上铺天盖地都是 AI 焦虑的视频，可另一头，居然还有大学生心甘情愿把钱送给闲鱼上的无良商家。我严重怀疑咱们根本不在一个时间线里。既然学了计算机，网上一点职业相关的动态都不刷吗？2023 年 AI 还没成气候也就罢了，**今年都 2026 年了！**

更让我匪夷所思的是，Java 和 C++ 代做也就忍了，连 Python 项目都有人找代做！我想说的不是 Python 有多简单，这早就不是难度的问题了。现在随便一个网页端 AI Agent（比如智谱清言 GLM、MiniMax）都能开发 Python 软件，Django、Flask 这些框架都能开发，还全是免费的。哪怕稍微了解一下当下的 AI 发展现状呢？根本没必要花这冤枉钱，难道网页都不会打开吗？这种思维逻辑本质上就是**得过且过**：能花钱解决就绝不费脑，绝不多思考一秒。这是一种极其弱智的生存策略。

这类网友我见过一些，也有一些是认识的朋友：比如某程序开发专业的大学生，在某个开源项目的视频底下问 Git 是什么、GitHub 为啥打不开；还有我在某个 Q 群里认识的网安专业老哥，大学混了三年，光顾着玩，电脑都没碰过一下。古有指鹿为马，今有**指 Linux 为华为系统**，而 Windows…被誉为安卓电脑。

如果说上面那是“蠢”，那接下来的操作就是纯粹“坏”了——**利用开源项目牟利**。闲鱼上有些给 GitHub 刷贡献墙的商家，但稍微搜一下就知道，这玩意儿就是 GitHub 上的一个开源工具 **`GreenWall`（绿墙）**。想要多少贡献随便填，全刷绿都行。可即便如此，依然有人花高价买这玩意儿优化简历。项目地址[点这里](https://github.com/zmrlft/GreenWall)。

当然，我也凑了个热闹，花了十几块钱，分别买了个刷星服务和一个新账号尝鲜。刷星服务倒是挺“专业”：那些刷星的假号有模有样，有 Issue、有 PR、有仓库还有 Fork，还是分批刷的，估计是为了躲风控。这点确实有一手，不过还是不提倡刷星，毕竟懂的都懂。听说 OpenClaw 就是刷星刷出来的项目，微软那边基本是睁一只眼闭一只眼。至于那个新账号……说实话，**毫无卵用**。真不如手动注册。大家想看可以去这瞧瞧：<https://github.com/exyone-dev>。我已经换上了自己的 ID、密码，绑定了邮箱和 2FA。总结就是：除非这账号自带 **GitHub Pro**，否则真没必要买，纯属智商税。哪怕你是想要整一个老号，也用不到这玩意，上面那个绿墙工具就能帮你实现了，在十几年前的年份刷贡献就可以让那一年出现在贡献墙上，也因此可以让账号看起来资历更老。

_更新：买的这个账号似乎已经被 GitHub 云控了，现在无论是提交 PR 还是创建 Issue，别人都是看不到的。_

## 再谈张雪峰

张雪峰是一个极具争议性的人物，但不得不指出，计算机专业的混子数量之多，和张雪峰绝对脱不了干系。张雪峰在两、三年前的时候力荐计算机专业，导致大量大一新生涌入计算机专业，质量参差不齐是一方面，另一方面，计算机专业是一个对学习能力要求极高的专业。那时候，张雪峰的话被很多家长奉为圭臬——尤其是那些自身毫无主见、却又控制欲极强的家长。他们只记住了**“计算机好就业”**，但对专业内容、行业门槛、孩子特质一概不知。

更令人唏嘘的是，这批学生的家庭背景大多透着一种无力感：很多孩子从小到大几乎没正经碰过电脑，结果刚进大一，家长反倒大手一挥，直接配齐了**“华为全家桶”**。让一个对计算机毫无基础、心智尚未成熟的孩子，突然闯进一个极度依赖自学能力和信息素养的领域，本身就埋下了隐患。这些大一新生接触到外面的世界之后变得浮躁了，完全沉不下心去学习了。

在两、三年前，网络上还有人会说：“计算机和起点无关，穷人家的孩子只要肯学，照样能出头。”当然，这句话确实说得很对，我也支持这种观点，但现实情况是绝大多数人根本没有那么好的自控力；小学和中学，孩子没有接触过外面花花绿绿的世界，还能保持朴素的心态，可一旦踏入大学，诱惑扑面而来，还能守住本心、不随波逐流的人少之又少。**这就好比把一只从小关在笼里的鸟突然放飞，却指望它依然安分地在铁栏里歌唱——未免太过理想化。**计算机专业对学习能力的要求极高，因为技术栈只会不断更新迭代，没有人能靠着**jQuery 和 BootStrap**干一辈子不失业。如今，再没人敢轻易劝人学计算机了。为什么？因为一个几年前人挤人的专业，稍有常识的人都看得出来：迟早该饱和了。
