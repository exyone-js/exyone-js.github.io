# Exyone Blog

> Exyone's Home Page. Powered by [Jekyll](https://jekyllrb.com/).

## Features

- **Clean & Minimal:** Three-column layout with a classic minimalist card design.
- **Dark Mode:** Automatically switches between dark and light themes based on system preferences.
- **Responsive:** Adapts from three columns on desktop, to two columns on tablet, and one column on mobile.

## Quick Start

Before you begin, make sure you have Node.js and npm installed.

```bash
# Start local development server with hot reload
jekyll serve

# Build production-ready files
jekyll build
```

The production build will be generated in the `_site/` directory.

## Project Structure

```text
.
├── _data/          # Global data files
├── _includes/      # Template components
├── _layouts/       # Layout templates
├── _posts/         # Blog posts
├── pages/          # Standalone pages
├── assets/         # Static resources
│   ├── css/        # Stylesheets
│   ├── js/         # JavaScript files
│   └── images/     # Images
└── media/          # Post media
```
