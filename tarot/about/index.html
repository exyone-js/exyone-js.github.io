说明

Ratio Operis

这是什么 Quid Est

一个用彩窗与金饰写成的塔罗牌阵工具，六种玩法，从一张到十张。

牌义沿用通行的塔罗系统（22 张大阿卡纳与四个花色），每一张另附一段与天主教德行传统的对照， 作为默想的引子。抽牌是随机的，读牌的是你自己。

使用方式：从牌阵页进入抽牌台 → 洗牌、切牌 → 逐张翻开 → 解读页会给出逐位牌义与整体整理。 结果会以网址参数的形式保存在链接里，可以直接分享或收藏。

六种牌阵

Sex Ordines

圣言一牌 Signum

「求你使我清晨得闻你的慈爱，因为我倚靠你。」（咏 143:8）

只抽一张。为今天定一个默想的方向。

  1. 今日圣言 Verbum Hodiernum — 今天最值得放在心上的一句话、一份提醒。

静下来，把今天最挂心的一件事交给这一次抽牌，然后翻开一张。

信望爱三德阵 Tria

「现今存在的，有信、望、爱这三样，但其中最大的是爱。」（格前 13:13）

三张牌，检视一件心事里的信、望、爱。

  1. 信德 Fides — 你所立足、所信靠的究竟是什么。
  2. 望德 Spes — 在等待之中，你所能盼望的方向。
  3. 爱德 Caritas — 这件事里，爱要求你如何去行。

适合问一件正在走的路：我信的是什么？我盼望什么？我爱的是谁？

圣十字阵 Crux

「你们求，必要给你们；你们找，必要找着。」（玛 7:7）

五张牌，看清此刻的处境与可用的助力。

  1. 此刻 In Medio — 你真正站立的位置，与事情的核心。
  2. 恩宠 Gratia — 已经赐下、却可能被忽略的那份帮助。
  3. 根基 Fundamentum — 这一切底下真正的地基，往往是旧事。
  4. 阻碍 Impedimentum — 挡在路上、需要被诚实面对的东西。
  5. 助力 Auxilium — 可以立刻取用的人、资源或态度。

适合问一个具体的决定：现况是什么，什么在拦我，什么能帮我。

双途阵 Duae Viae

「你们应站在路上察看，探问旧路——那是善道，便行在其间。」（耶 6:16）

六张牌，把两条路各看到底。

  1. 甲途 · 开端 Via Prima · Initium — 选择甲路，最先会遇到什么。
  2. 甲途 · 代价 Via Prima · Pretium — 走甲路必须付上的代价。
  3. 甲途 · 收获 Via Prima · Fructus — 甲路最终会长成什么样子。
  4. 乙途 · 开端 Via Altera · Initium — 选择乙路，最先会遇到什么。
  5. 乙途 · 代价 Via Altera · Pretium — 走乙路必须付上的代价。
  6. 乙途 · 收获 Via Altera · Fructus — 乙路最终会长成什么样子。

适合二选一：先在纸上写下甲、乙两条路，再依序翻开六张。

七德阵 Rosarium

「圣神的效果是：仁爱、喜乐、平安、忍耐、良善、温和、忠信、柔和、节制。」（迦 5:22-23）

七张牌，围绕七种德行查验自己。

  1. 信德 Fides — 我真正信靠的是什么。
  2. 望德 Spes — 我仍在盼望什么，或已经放弃盼望什么。
  3. 爱德 Caritas — 爱在我身上是否还活着。
  4. 明智 Prudentia — 我该在何处放慢、何处加快。
  5. 公义 Iustitia — 我亏欠了谁，需要如何补还。
  6. 刚毅 Fortitudo — 哪一件事，我不能再回避。
  7. 节制 Temperantia — 哪一处失了分寸，需要收回。

适合一段长时间的自我检视，例如月初或避静之前。

大十字阵 Magnus Ordo

「事事有时节，天下任何事皆有定时。」（训 3:1）

十张牌。最完整的一次梳理，看清来龙去脉。

  1. 现况 Status — 此刻的中心，事情本来的样子。
  2. 阻力 Impedimentum — 横在现况之上的那股力量。
  3. 根源 Radix — 这一切底下真正的地基。
  4. 将逝 Occasus — 正在退场、该放手的东西。
  5. 显意识 Conscium — 你清楚知道并挂在心上的。
  6. 潜意识 Subconscium — 你还未承认，却已在影响你的。
  7. 自我 Ipse — 你在这件事里的姿态与位置。
  8. 环境 Ambitus — 他人与处境带给你的影响。
  9. 希望与恐惧 Spes et Timor — 你所期待与所害怕的，往往是同一件事。
  10. 归宿 Exitum — 若一切照现状发展，最可能的落点。

牌较多，请预留一段安静的时间；适合季度回顾或重大抉择。

牌的构成

De Structura

大阿卡纳 Arcana Maiora

22 张 · 0 – XXI

从「愚者」到「世界」，描述一段完整的历程。牌阵里出现得越多，通常意味着这件事越关乎整体方向，而非细节。

小阿卡纳 Arcana Minora

56 张 · 四花色 × 14

  • 权杖 · Virgae — 火；行动 · 志业 · 创造；相应德行：热忱与勇毅
  • 圣杯 · Calices — 水；情感 · 关系 · 灵修；相应德行：慈悲与爱德
  • 宝剑 · Gladii — 风；思辨 · 言语 · 试炼；相应德行：真理与明辨
  • 星币 · Nummi — 土；劳作 · 身体 · 受造界；相应德行：忠信与勤勉

数据与隐私

De Notitia

  • 抽牌结果写在网址参数中（例如 ?spread=tria&c=12.1,45.0,7.1），刷新或分享都不会变。
  • 主题（昼 / 夜）与占卜记录存在本机 localStorage，不上传、有数量上限。
  • 「今日一牌」由当天日期推算，同一天永远是同一张。
  • 整站是构建期生成的静态页面，没有任何后端与追踪脚本。
